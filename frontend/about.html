About HindiOCRExcel

An open, production-ready pipeline that converts scanned images and PDF documents containing tabular data into editable, formatted Excel files — with first-class support for Hindi, English and mixed-language content.

How it works

  1. Your image or PDF is validated and stored server-side.
  2. PDF pages are rendered to images (PyMuPDF).
  3. An OpenCV pipeline deskews, denoises and enhances each page.
  4. Table lines are detected to build a grid of cells (with a layout-clustering fallback for line-less tables).
  5. PaddleOCR reads each cell — Devanagari, Latin and numerals.
  6. The table is reconstructed, merged across pages and returned as JSON.
  7. You edit it in the browser and export a Unicode-safe .xlsx (OpenPyXL).
